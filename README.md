# Cadastro API - Projeto para Tópicos Especiais de Sistemas

Este projeto é uma aplicação Web API desenvolvida em C# utilizando o modelo mínimo do .NET 7 e Entity Framework com banco de dados SQLite. Ele faz parte do trabalho da disciplina **Tópicos Especiais de Sistemas**.

## 🎯 Objetivo

Criar uma API RESTful para gerenciamento de pessoas e cidades com suporte a operações CRUD completas, incluindo validações e relacionamento entre entidades.

## 🚀 Como Executar

### Pré-requisitos:
- .NET 7 SDK instalado: https://dotnet.microsoft.com/download

### Passos:

1. Clone o repositório:
   ```bash
   git clone https://github.com/seuusuario/seurepositorio.git

2. Acesso ao diretorio:
    cd CadastroApi

3. Restaure os pacotes:
    dotnet restore

4. Aplique as migrations:
    dotnet ef database update

5. Execute a aplicação:
    dotnet run

6. Acesso ao Swager para testar:
    http://localhost:5000/swagger
